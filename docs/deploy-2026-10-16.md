## Compatibilità del confezionamento su Windows

Il helper di sincronizzazione ha completato build, commit e push, ma la fase archive ha selezionato il Bash WSL di sistema con percorsi Windows non compatibili. È stata ripetuta soltanto la fase fallita usando lo stesso `package-site.sh` della skill, Git Bash e percorsi `/c/Users/...` per sorgente e archivio. L’archivio proviene dal commit già pubblicato, senza modifiche successive del sorgente.

Per un successivo deploy da questo computer, mantenere identità del sito e migrazioni. Il helper gestisce le credenziali tramite stdin, mai file o argomenti di shell. In caso di analogo errore, usare il packager originale con Git Bash e percorsi POSIX; non rigenerare il sito o le risorse dati.
